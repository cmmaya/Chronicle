# BU013 — UI Integration

Status:
Pending

Goal:
Integrate SessionManager with the MainWindow UI to enable core user workflows: creating sessions, recording audio, and viewing the final transcript.

Context:
This BU connects the newly refactored backend to the frontend UI, making the application's core features accessible to the user. This was originally BU008, now updated to work with the dual-source architecture.

Allowed Files:
- `src/app/window.py`
- `src/app/session_manager.py`
- `src/main.py`

Dependencies:
Required:
- BU012

Blocks:
- None

Tasks:
- Instantiate `SessionManager` within `MainWindow`.
- Add "Start Session" and "Stop Session" buttons.
- Add a status display for session state (e.g., "Recording", "Stopped", "Transcribing").
- Connect UI buttons to `SessionManager` methods (`start_session`, `stop_session`).
- When a session is stopped and the final transcript is generated, load and display `transcript.txt` in a text area in the UI.

Out of Scope:
- Real-time transcript display.
- Screenshot controls.
- Session history view.

Definition of Done:
[ ] Application launches and displays session control buttons.
[ ] Clicking "Start Session" creates a new session and begins dual-source recording.
[ ] Status display updates to "Recording".
[ ] Clicking "Stop Session" stops recording, starts transcription, and triggers the merge process.
[ ] Status display updates accordingly.
[ ] The final merged transcript is displayed in the UI upon completion.

Reviewer Focus:
- Correctness of Qt signal/slot connections.
- Proper lifecycle management of the `SessionManager`.
- UI responsiveness and correct display of the final transcript.
