# BU009 — Notion Sync

Status:
Pending

Goal:
Sync generated meeting summaries to a Notion database.

Context:
This BU provides the final step in the primary workflow, allowing users to push their structured meeting notes to an external knowledge base.

Allowed Files:
- src/sync/notion.py
- src/app/session_manager.py
- src/app/window.py

Dependencies:
Required:
- BU008

Blocks:
- none

Tasks:
- Implement Notion API client in `src/sync/notion.py`.
- Add methods to create/update Notion pages from a summary.
- Add a "Sync to Notion" button/action in the UI.
- Integrate the Notion client into the `SessionManager` or `MainWindow` to be called after a summary is generated.
- Handle Notion API keys and database ID (can be hardcoded or placed in a config for now).

Out of Scope:
- Complex Notion block types (e.g., tables, embeds).
- Two-way synchronization.
- UI for managing Notion credentials.

Definition of Done:
[ ] A "Sync to Notion" action is available in the UI after a session is completed.
[ ] Invoking the action creates a new page in a specified Notion database.
[ ] The Notion page is populated with the key points, action items, and decisions from the generated summary.
[ ] Errors during the sync process are logged.

Reviewer Focus:
- Secure handling of API credentials.
- Robustness of the Notion page creation logic.
- Clear separation of sync logic from core application logic.
