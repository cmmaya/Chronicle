# BU008 — UI Integration

Status:
Pending

Goal:
Integrate SessionManager with the MainWindow UI to enable core user workflows: creating sessions, recording audio, and triggering transcription.

Context:
This BU connects the backend logic (SessionManager) to the frontend UI (MainWindow), making the application's core features accessible to the user for the first time.

Allowed Files:
- src/app/window.py
- src/app/session_manager.py
- src/main.py

Dependencies:
Required:
- BU006
- BU007

Blocks:
- BU009

Tasks:
- Instantiate SessionManager within MainWindow.
- Add a central widget to MainWindow to hold session controls.
- Add "Start Session" and "Stop Session" buttons.
- Add a status display to show the current session state (e.g., "Recording", "Stopped", "Transcribing").
- Connect UI buttons to SessionManager methods (`start_session`, `stop_session`).
- Modify session logic to automatically start recording when a session starts.
- Modify session logic to automatically trigger `process_transcriptions` when a session is stopped.

Out of Scope:
- Displaying the transcript in the UI.
- Screenshot controls.
- Session history view.

Definition of Done:
[ ] Application launches and displays session control buttons.
[ ] Clicking "Start Session" creates a new session and begins recording.
[ ] Status display updates to "Recording".
[ ] Clicking "Stop Session" stops the recording and starts transcription.
[ ] Status display updates to "Transcribing", and then "Completed".
[ ] A session folder with audio and transcript files is created locally.

Reviewer Focus:
- Correctness of Qt signal/slot connections.
- Proper lifecycle management of the SessionManager.
- UI responsiveness during state transitions.
